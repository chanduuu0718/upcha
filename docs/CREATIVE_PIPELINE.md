# Creative pipeline

After a user selects a Myntra product, Upcha should create a new promotional image rather than simply reposting the source image.

## V1

```text
Myntra URL
  ↓
Product preview
  ↓
User selects product
  ↓
Product metadata + source image
  ↓
Choose creative template
  ↓
Render new vertical creative
  ↓
Preview creative
  ↓
Approve
```

## Design rules

- Use a Pinterest-friendly vertical canvas.
- Keep the product visually dominant.
- Use short, readable copy.
- Include a clear call to action.
- Do not invent product facts, prices, discounts, ratings, or scarcity.
- Keep the destination/affiliate URL separate from the image asset.

## Later

Add multiple creative variants, category-aware template selection, AI-assisted copy, and performance-based template selection without changing the product-selection contract.
